# Critter Survivor

Survivor-like em canvas (HTML/JS puro). Quiz define seu animal inicial; 49 animais, 8 golpes por animal (golpes de classe + únicos da espécie), roleta com tickets.

- Jogar: https://aristeu-junior.github.io/critter-survivor/
- Controles: WASD/setas ou arrastar na tela (celular).
- Sprites: recortados da folha fornecida (`tools/segment.py`, `tools/export.py`). Os 5 felinos exóticos (tigre, leão, onça, pantera, leopardo-das-neves) são recolors provisórios — trocar por arte própria.
- Compra de tickets dourados: **não há pagamento real integrado**; o botão de teste deve ser removido antes de lançar.
- Atalho de teste: `?demo=<id>` (ex.: `?demo=tigre&all=1`).
